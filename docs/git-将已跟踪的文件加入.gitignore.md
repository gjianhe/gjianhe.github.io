
# git-将已跟踪的文件加入.gitignore

## 背景

有时不小心将一个不应该被提交的文件（比如包含敏感信息的配置文件、本地日志、编译产物）添加到了 Git 并进行了提交，修改了 `.gitignore` 文件，希望以后忽略这个文件；-但 `.gitignore` **只对未被跟踪的文件有效**。对于已经被 Git 跟踪的文件，`.gitignore` 无法使其停止被跟踪。

## 解决方法

先使用 `git rm --cached <file>` 将文件从 Git 的索引中移除（停止跟踪），然后再提交这个更改。之后，该文件就会受到 `.gitignore` 规则的影响，不再被纳入版本控制。
