# macOS-基本操作快捷键

macOS 提供了许多便捷的键盘快捷键，可以帮助用户更快捷地进行各种操作。以下是一些常用的 macOS 快捷键：

## 基本操作
- `Command + Tab`：在打开的应用程序之间切换。
- `Control + 空格`：切换输入法
- `Command + Shift + Tab`：反向顺序切换应用程序。
- `Command + Space`：打开 Spotlight 搜索。
- `Command + Q`：退出当前应用程序。
- `Command + H`：隐藏当前应用程序窗口。
- `Command + M`：最小化当前窗口到 Dock。
- `Command + N`：新建一个窗口或文件。
- `Command + W`：关闭当前窗口。
- `Command + Z`：撤销上一步操作。
- `Shift + Command + Z`：重做上一步撤销的操作。
- `Command + C`：复制选定的内容。
- `Command + X`：剪切选定的内容。
- `Command + V`：粘贴内容。
- `Command + A`：全选内容。
- `Command + D`：复制当前选中的文件或文件夹。
- `Command + S`：保存当前文件。
- `Command + Shift + S`：显示“另存为”对话框。
- `Command + Shift + C`：显示剪贴板。
- `Command + Shift + D`：显示字典。
- `Command + Shift + E`：显示事件查看器。
- `Command + Shift + F`：显示查找器。
- `Command + Shift + G`：显示“前往文件夹”对话框。
- `Command + Shift + H`：隐藏所有其他应用程序。
- `Command + Shift + K`：显示终端。
- `Command + Shift + L`：显示登录项。
- `Command + Shift + M`：显示磁盘工具。
- `Command + Shift + N`：打开新的 Finder 窗口。
- `Command + Shift + O`：显示打开对话框。
- `Command + Shift + P`：显示打印对话框。
- `Command + Shift + R`：显示重新安装 macOS 对话框。
- `Command + Shift + T`：重新打开最近关闭的标签页。
- `Command + Shift + U`：显示语音控制。
- `Command + Shift + V`：粘贴并匹配样式。
- `Command + Shift + W`：关闭所有窗口。
- `Option + Command + 空格`：显示语言和区域偏好设置。
- `Command + Option + Esc`：强制退出应用程序。
- `Command + Shift + Delete`：显示“清理历史记录”对话框。
- `Command + Shift + 4` 或 `Command + Shift + 4` 然后按空格：屏幕截图或选定区域截图。
- `Command + Shift + 5`：打开屏幕截图工具。
- `Control + 空格`：显示输入法选择器。
- `Command + Shift + 3`：截取整个屏幕的截图。
- `Control + Command + 空格`：显示字符查看器。
- `Option + Command + 空格`：显示语言和地区偏好设置。
- `Command + Shift + Escape`：显示活动监视器。
- `Control + Command + F`：全屏模式。
- `Command + Shift + F3`：退出全屏模式。
## 窗口操作
- `Control + 拖动窗口`：调整窗口大小。
- `Option + Command + F`：显示 Finder 窗口。
- `Option + Command + N`：新建智能文件夹。
- `Option + Command + T`：显示标签栏。
- `Option + Command + W`：关闭所有窗口。
- `Option + Command + Z`：撤销上一步操作（某些应用程序中可用）。
## 系统偏好设置
- `Command + ,`：打开当前应用程序的偏好设置。
- `Option + Command + K`：显示键盘快捷键偏好设置。

这些快捷键可以帮助你在 macOS 中更高效地操作计算机。熟悉这些快捷键可以大大提高你的工作效率。如果有特定的应用程序或功能上的快捷键需求，可以随时询问。
