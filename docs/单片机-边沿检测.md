
# 单片机-边沿检测

```c
uint8_t check_edge(uint8_t cur_sta, uint8_t *pre_sta)
{
	uint8_t edge = cur_sta ^ pre_sta[0];
	pre_sta[0] = cur_sta;
	return edge << 1 | cur_sta;
}

uint8_t check_edge(uint8_t cur_sta, uint8_t *pre_sta)
{
	uint8_t edge = cur_sta << 1 | pre_sta[0];
	pre_sta[0] = cur_sta;
	return edge;
}
```

## 原理
1. 通过异或来确定信号是否有变化
2. 通过返回值来确定各种状态
	1. 3(0b11)：上升沿（电平变化且当前为高电平）
	2. 2(0b10):下降沿（电平变化且当前为低电平）
	3. 1(0b01):稳定高电平
	4. 0(0b00):稳定低电平
