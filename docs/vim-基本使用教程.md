# vim-基本使用教程

- `:w`：保存当前文件
- `w filename`：没指定文件名则保存文件，打开时候指定文件名，则另存为
- `:q`：退出当前正在编辑的文件
- `q!`：强制退出当前正在编辑的文件并放弃最近一次保存到现在的更改
- `wq`：保存文件并退出
- `u`：撤销最近一次操作
- `i`：在光标所在的位置右边插入字符
- `a`：在光标所在的位置左边插入字符
- `o`：在光标所在行的下一行插入新的一行
- `O`：在光标所在行的上一行插入新的一行
- `s`: 删除当前字符并插入
- `S`: 删除当前行并插入
- `gg`：跳到文本的第一行
- `G`：跳到文本的最后一行
- `:%s/old/new`：将文件中所有的`old`字符串替换成字符串`new`
- `/string`：从光标处往下查找字符串`string`，注意输入完字符串后要按回车键
- `?string`：从光标处往上查找字符串`string`，注意输入完字符串后要按回车键
- `n`：把光标移至所查找字符串的下一个位置
- `N`：把光标移至所查找字符串的上一个位置
- `nG`：跳到文件的第n行，`1G`等价于`gg`
- `$`：移至行尾
- `0`：移至行首
- `M`：移至屏幕中间
- `H`：移至屏幕第一行
- `L`：移至屏幕最后一行
- `yy`：复制当前行
- `dd`：剪切当前行
- `p`：粘帖
