
# 蓝牙模块总结


## 蓝牙类别

| 蓝牙类别  |      标志      |       特性       |
| :---: | :----------: | :------------: |
| 经典蓝牙  | SPP，蓝牙3.0及以下 |    功耗高，速率较快    |
| 低功耗蓝牙 | BLE，蓝牙4.0及以上 |    功耗低，速率较慢    |
| 双模蓝牙  |   SPP+BLE    | 同时集成经典蓝牙和低功耗蓝牙 |


## 主从类别

| 主从类别 |               特性               |
| :--: | :----------------------------: |
| 单从机  |     仅能被动等待主设备连接，无法主动发起连接请求     |
| 主从一体 | 可切换角色为主设备或从设备，作为主设备时，可主动发起连接请求 |


## 常见蓝牙分类

- HC-04：双模蓝牙SPP2.0+BLE4.0
- HC-05：经典蓝牙SPP2.0
- HC-08：低功耗蓝牙BLE4.0
- JDY-31：经典蓝牙SPP3.0
- JDY-33：双模蓝牙SPP3.0+BLE4.2
- BT16：低功耗蓝牙BLE4.2
